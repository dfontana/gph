# gph

`gph` is a small, Kitty-native Mermaid previewer. It uses
[merman](https://github.com/Latias94/merman) for parsing, layout, SVG, and PNG
rendering, watches source files for changes, shows a live Kitty image preview, and
exports SVG files.

There is no custom diagram language, manual node positioning, mouse interaction,
or browser/Node runtime. Mermaid decides all layout.

## Install

```sh
cargo install --path .
```

The crate requires Rust 1.95 or newer. Live previews require Kitty.

## Watch with a live preview

```sh
gph watch diagram.mmd
```

Run the watcher in its own terminal pane and edit the Mermaid file with any editor.
`gph` uses native file-system notifications and debounces a burst of save events
before rerendering. The preview starts below the command's existing terminal
output and grows downward when its pane is resized; it never enters the alternate
screen. Invalid Mermaid leaves the
last valid preview visible and reports the error in the preview border. Press
`Ctrl-C` or `Ctrl-Q` to quit.

## Export SVG

```sh
gph export diagram.mmd -o diagram.svg
printf 'flowchart TD\nA --> B\n' | gph export - -o diagram.svg
```

The destination must end in `.svg`. Failed rendering never writes the output.

## Scope

- Kitty graphics protocol only; no Sixel, iTerm, or text fallback.
- Mermaid syntax only; no DSL conversion, Markdown transformation, or format
  exports beyond SVG.
- Node locations are always generated by Mermaid/merman.
