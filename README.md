# gph

`gph` is a small, Kitty-native Mermaid editor. It edits Mermaid source directly,
uses [merman](https://github.com/Latias94/merman) for parsing, layout, SVG, and
PNG rendering, shows a live Kitty image preview, and exports SVG files.

There is no custom diagram language, manual node positioning, mouse interaction,
or browser/Node runtime. Mermaid decides all layout.

## Install

```sh
cargo install --path .
```

The crate requires Rust 1.95 or newer. The editor requires Kitty.

## Edit with a live preview

```sh
gph edit diagram.mmd
gph edit diagram.mmd --create
```

`--create` writes a small flowchart starter and refuses to overwrite an existing
file. Every keystroke is saved to the source file and triggers a fresh preview.
Invalid Mermaid remains saved, its error is shown in the status bar, and the
last valid preview stays visible. Press `Ctrl-Q` or `Ctrl-C` to quit.

## Export SVG

```sh
gph export diagram.mmd -o diagram.svg
printf 'flowchart TD\nA --> B\n' | gph export - -o diagram.svg
```

The destination must end in `.svg`. Failed rendering never writes the output.

## Scope

- Kitty graphics protocol only; no Sixel, iTerm, or text fallback.
- Mermaid syntax only; no DSL conversion, Markdown transformation, or format
  exports beyond SVG.
- Keyboard editing only. Node locations are always generated by Mermaid/merman.
